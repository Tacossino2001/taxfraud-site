Come entrare nel server

     
           
  1. Scarica Forge per la versione 1.20.1 ed esegui l'installazione.
    2.        
  2. Scarica Pacchetto completo dal box sopra.
    3.        
  3. Estrai i file contenuti nella cartella ZIP e mettili nella cartella AppData/Roaming/minecraft/mods.
    4.        
  4. Avvia Minecraft con l'installazione Forge.
    5.        
  5. Aggiungi il server con IP taxfraud.info e connettiti.
    6.        
  6. Connetti il tuo account Discord al tuo profilo Minecraft, segui le istruzioni indicate nella schermata di gioco.
    7.      
     

Problemi comuni

     
           
  • Crash: Versione di Forge sbagliata o mod mancanti.
    •        
  • Server offline: Controlla lo stato del server su Discord.
    •        
  • Connessione non riuscita: segui le istruzioni indicate nel messaggio di errore, se necessario apri un Ticket nel server Discord.

Hai errori?
         
3 problemi risolti subito
       
       
             
  • Manca una mod: scarica l’ultimo update e rimetti nella cartella mods.
    •          
  • Versione sbagliata: usa sempre Forge 1.20.1 alla sua ultima versione stabile.
    •          
  • Timeout: controlla che taxfraud.info risolva e che il server sia online su Discord.
